# 0001. Rust as the language

Status: Accepted
Date: 2026-11-18

## Context

The software must be fluid on an ordinary laptop, reliable on real projects,
and maintained by a small team helped by AI assistants. Most of the code
will be written with AI help and reviewed by people who are still learning.

## Decision

OPEN-ARCHIBIM is written in Rust.

## Consequences

- Speed comparable to C++, without garbage-collection pauses: good for
  fluid display.
- The compiler rejects whole classes of errors (memory, data races) before
  the program runs. It is the first reviewer of every change, human or AI.
- `cargo`, `rustfmt` and `clippy` give one standard way to build, format and
  check code.
- The Rust IFC ecosystem is young: we write our own IFC reader and writer
  from the public specification, which fits our choice to own the building
  model.
- Robust Boolean operations on solids are the hardest geometry problem. The
  Stage 0 prototype compares an existing library with our own code.
- The interface toolkit (candidates: `egui`, `iced`) is chosen by the
  prototype, in a separate record.
