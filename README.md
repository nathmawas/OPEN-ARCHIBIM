# OPEN-ARCHIBIM

**Open-source BIM software, for architects and by architects.**

A lean, open design tool that serves the project. IFC is its native format.
Drawings come out of the model ready to print. You never pay a subscription to
open your own work, and AI is never forced on you.

- 📜 [Manifesto](MANIFESTO.md): why, and on which principles
- 🗺️ [Roadmap](ROADMAP.md): what we build, in which order, and how long it takes
- 🧰 [Tools](TOOLS.md): what we keep, what we simplify, what we drop
- 🏗️ [Architecture](ARCHITECTURE.md): how the software is built, and why

## Status

Stage 0: foundations. There is no usable code yet.

## Languages

The project is written in English: code, documentation, issues and commits.
The application itself ships with language packs. The first six are
**English, French, Spanish, Italian, German and Portuguese**, and more are
welcome.

## Contributing

Are you an architect? Open an issue that describes **one concrete gap** in the
tool you use today, with a real case. Are you a developer? Read the roadmap,
especially the technical approach. Speak another language?
Help translate the application.

**Clean-room rule:** no reverse engineering. Never reuse code, text or
internal formats from proprietary software.

Read [CONTRIBUTING.md](CONTRIBUTING.md) before your first contribution.
